# Library Management System

An interactive web app that allows users to add, display, and manage their personal library. The app uses local storage to persist books across page reloads. Features include adding books, marking books as read/unread, and removing books from the library.

## About The Project
🎥 [Watch the Demo Video on YouTube](https://youtu.be/Zkut059TqA4)

This is a personal library management app where users can:
- Add new books with details like title, author, pages, and year.
- Mark books as read/unread.
- Remove books from the library.
- Store the library in local storage, so it persists across page reloads.

### Why This Project?
This project was created to help users organize their reading collection in a simple and visually appealing way. It allows for easy management of book details and offers a seamless experience for adding, editing, and removing books.

## Built With

### Usage
Once you open the web app, you will see the homepage with buttons to add a book or view the collection.

#### Add a New Book
Click on the "Add a book" button to fill out a form and add the book details.

Upon submission, the book is saved to localStorage and will be displayed in your library collection.

#### View Collection
Clicking "View your collection" will take you to the storage page, where all books are displayed in card format.

#### Toggle Read Status
You can change the "read" status of a book by clicking the "Toggle Read" button next to each book.

#### Remove Book
You can remove a book from the collection by clicking the "Remove" button on its card.
